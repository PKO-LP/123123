# Руководство пользователя (Manual)
## Запуск
1. Установите Python 3.14.2 (`tkinter` встроен).
2. Положите файлы `app.py` и `logo.png` в одну папку.
3. Запустите `python app.py`.
## Работа и ошибки
- Введите название и дни, нажмите **«Добавить задачу»** для записи или **«Очистить поля»** для сброса.
- Если картинка не открывается, пересохраните `logo.png` через **Paint** в формат PNG.
